# Cooking Recipe Portal

A responsive web-based Cooking Recipe Portal built using React and Vite.

## Features

- User Registration and Login
- Explore Recipes
- Search, Filter and Sort Recipes
- Recipe Details
- Create and Manage Recipes
- Ingredients and Cooking Instructions
- Favorites
- User Dashboard
- User Profile
- Reviews and Ratings
- Notifications
- Admin Dashboard
- Category Management
- Moderator Dashboard
- Reports and Review Management

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
- React Router DOM
- Local Storage

## Installation

1. Clone the repository.
2. Open the frontend folder.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the localhost URL displayed in the terminal.
